# Reporting Screen Corrections

 - The dialog to change the budget must include both limit and frequency
 - The list of tags should be at the bottom of the screen, so the report is the first thing seen.
 - The tag list is just a table with tag name and spending.  No other widgets are needed.  The table columns can be sorted in descending or ascending order.  
 - Cannot drag the tags in the list to the reporting area. Dragging does not change the order in the tag list, only adds them to the reporting area.  The order in the reporting area is completely flexible and you can place a tag anywhere in the reporting area.  The reporting area is also a scrollable list.  So you can't just put tags in any location, just to a new location in the list.
 - The bar chart in the reporting area should look like a simple bar chart, with verticle lines for each period in the tag frequency.  So if it is just a single budget limit for the whole month, then it should be a single bar, with lines for the beginning and end of the month as well as a horizontal line for the limit, and another horizontal line for the spending.
